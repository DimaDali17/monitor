# EasyForm Dashboard

Аналитика WB (Easyform + EZFR) и Ozon: заказы, остатки, дефицит, консолидация.

Дашборд лежит на GitHub Pages. Ключи маркетплейсов в нём отсутствуют —
они живут в секретах Cloudflare Worker, который проксирует запросы.
Пользователь вводит только пароль.

## Что где

    index.html      дашборд
    css/ js/        его код
    worker.js       прокси для Cloudflare — на Pages не используется

## Развернуть — один раз, всё мышкой

### 1. Файлы на GitHub

Залить содержимое репозитория как есть. Затем Settings → Pages →
Source: Deploy from a branch, ветка main, папка / (root).
Через минуту дашборд открыт по адресу вида https://ник.github.io/репозиторий/

### 2. Воркер на Cloudflare

Панель → Workers & Pages → открыть свой воркер → Edit code.
Вставить содержимое worker.js целиком вместо старого кода → Deploy.

### 3. Секреты

Тот же воркер → Settings → Variables and Secrets → Add.
Тип **Secret** (значение шифруется и больше не показывается):

    DASH_PASSWORD    пароль, который вводят пользователи
    SESSION_SECRET   случайная строка, любые 40+ символов из головы
    WB_KEY_1         ключ WB, кабинет Easyform (категория «Статистика»)
    WB_KEY_2         ключ WB, кабинет EZFR
    OZON_CLIENT_ID   Client-Id Ozon
    OZON_API_KEY     Api-Key Ozon

Тип **Text**:

    ALLOWED_ORIGIN   https://ник.github.io — адрес дашборда без пути

Save and deploy.

### 4. Адрес воркера в дашборде

Если адрес воркера не совпадает с тем, что уже прописан — поправить
первую константу в js/config.js:

    export const WORKER = "https://ваш-воркер.workers.dev";

## Как пользоваться

Ссылку на GitHub Pages можно давать кому угодно: без пароля дашборд
не покажет ни одной цифры и не сделает ни одного запроса. Пароль
проверяет воркер, поэтому правкой JS в браузере это не обходится.
Пропуск действует 12 часов, кнопка «Выйти» его стирает.

Сменить пароль = перезаписать секрет DASH_PASSWORD. Выданные пропуска
при этом останутся действительными до конца суток; чтобы обрубить их
немедленно, перезапишите заодно SESSION_SECRET.

## Лимиты Wildberries

WB считает лимит Statistics API по ключу и продлевает бан за каждую
попытку внутри окна блокировки. Поэтому: пауза 20 с между запросами,
повтор через 60/90/120 с, кэш на 10 минут в браузере и на воркере.
На 429 воркер отдаёт последнюю удачную копию — данные будут слегка
несвежими, но дашборд не ляжет.

Первая загрузка Easyform заметно медленнее прежней. Это плата за то,
что WB перестаёт банить.
